# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm install           # install dependencies
npm run dev           # serve dist/ at http://localhost:5500
npm run build         # full production build → dist/
npm run watch:css     # recompile style.css → style.min.css on change (dev loop)
npm run minify:js     # minify main.js → main.min.js
npm run minify:css    # compile CSS once
```

There is no test suite and no linter configured.

## Architecture

This is a **vanilla HTML/CSS/JS** static site with a custom build pipeline. No framework, no bundler beyond the scripts below.

### Source vs. dist

Always edit source files — never touch `dist/` directly (it is fully regenerated by `npm run build`):

| Edit this | Gets compiled to |
|-----------|-----------------|
| `src/source.html` | `dist/index.html` |
| `src/assets/css/style.css` | `dist/assets/css/style.min.css` |
| `src/assets/js/main.js` | `dist/assets/js/main.min.js` |

`build.js` orchestrates the build: runs Tailwind CLI on the CSS, Terser on the JS, copies vendor JS and images, then minifies the HTML with `html-minifier-terser`.

### HTML structure (`src/source.html`)

The page has three top-level phases:

1. **`#intro`** — boot log sequence (`#boot-screen`) followed by lock screen (`#lock-screen`) with a Three.js/Canvas gradient mesh background
2. **`#desktop`** — full OS-like desktop: navbar, desktop icons, a `#win-container` where windows are mounted
3. **`#dock`** — mobile bottom dock

All app content lives in `<template id="tpl-{appId}">` elements at the bottom of `source.html`. Windows are created by cloning the matching template at runtime.

### JavaScript (`src/assets/js/main.js`)

Key globals:

- **`APP_CFG`** — map of app IDs to window config (title, icon, initial size/position)
- **`WM`** (Window Manager) — `WM.open(id)`, `WM.close(id)`, `WM.focus(id)`, `WM.openAll()`, `WM.closeAll()` — manages window lifecycle, z-index, dragging, resizing, and the navbar taskbar
- **`BOOT_LINES`** — array of strings for the boot log animation
- **`CMDS`** — terminal command handlers (`help`, `neofetch`, `whoami`, `ls`, `open`, `cat`, etc.)

Adding a new app requires: (1) an entry in `APP_CFG`, (2) a `<template id="tpl-{appId}">` in `source.html`, (3) optionally a desktop icon and/or dock button.

### CSS (`src/assets/css/style.css`)

Uses Tailwind CSS v4. Theme tokens are defined in `:root`:

```css
--accent: #7B6EFF;   /* primary violet */
--bg: #08080D;
--surface: #11111A;
--green: #3DD68C;
--coral: #FF7A5C;
--yellow: #F5C842;
```

### Deployment

GitHub Actions (`.github/workflows/static.yml`) runs `npm ci && npm run build` on every push to `main` and deploys `dist/` to GitHub Pages.
